Цель работы: 
Получить практический опыт работы с распределённой системой 
контроля версий Git с использованием облачного сервиса GitHub. Освоить 
базовые операции: клонирование, коммит, пуш, пулл, работа с ветками, 
создание Pull Request, ревью кода, управление задачами через Issues и 
Projects. 
Введение 
Система контроля версий (Version Control System, VCS) — это 
программный инструмент, который помогает отслеживать изменения в 
файлах, координировать работу нескольких разработчиков, восстанавливать 
предыдущие состояния проекта и анализировать историю изменений.
